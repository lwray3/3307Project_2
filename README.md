# Mirage: The Casino Game

Description: Mirage is a casino game developed using C++ and Qt, allowing players to play a variety of games similar to those seen in a casino.
Mirage currently includes Blackjack and Poker (Texas Hold Em), using Design Patterns such as the Factory Pattern and Flyweight Pattern. These patterns allow easier extensibility of the system. 

## Dependencies

- C++ 17 compiler
- Qt 6 
- Qt Creator


## Build and Run Instructions
- Clone the Github repo into your local IDE.
- If the IDE is not Qt Creator open the folder in Qt Creator
- Open the root CMakeLists.txt in Qt creator.
- Configure the project using a Qt 6 Desktop Kit
- Build and run the project by pressing the green play button on the bottom left od the screen

## Project Structure

- core/: Backend game logic (including Factory and Flyweight pattern implementation).
- ui/: Qt user interface and animations.
- report/: UML diagrams, design rationale, and forms.
- tests/: Automated Tests, not yet implemented will be a part of Deliverable 3.
